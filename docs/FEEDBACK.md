# 早期试用反馈

将以下内容交给试用邀请的发起者；也可在项目现有 GitHub Issues 中自行提交。反馈前先脱敏，仅提供复现所需的片段，不提供完整聊天、整个 `.latch/`、凭据或业务资料。

```text
版本／来源：CLI --version；源码快照或维护仓库 commit
环境：操作系统、架构、Node.js、pnpm、宿主及其版本（不确定就写未知）
问题类型：安装失败 / 流程卡住 / 恢复后遗漏或重复 / 不必要的人工打断
希望完成什么：
最少复现步骤：
预期结果／实际结果：
失败命令与退出码：
脱敏错误：error.code、next_action、phase、revision，以及必要的 stack 片段
恢复情况：中断点、恢复入口、哪些状态正确恢复、哪些丢失或重复
人工打断：当时已经提供了哪些授权，为什么认为再次询问不必要
```

用稳定占位符替换用户名、路径、任务标题、账号和业务内容。workspace proof 问题可附脱敏文件路径及 Git 状态、gate 前后改动类型；保留顺序和关系即可，不需要文件正文。不要先删除现场或放宽门禁来让流程通过。
